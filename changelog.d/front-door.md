### Added

- **One front door for 103 doc files, and a check that keeps it that way — Phase 37.5.** `docs/START-HERE.md` names the five documents a new user actually needs (`EXAMPLE.md`, `docs/adoption-guide.md`, `docs/user-guide.md`, `docs/tracks.md`, `ARCHITECTURE.md`); `README.md` and `docs/README.md` both point to it ahead of the existing exhaustive four-reader-path map, which is unchanged and still there for everyone else.

  `docs/historical/` and `docs/reference/` each gained a `README.md` index (the former lists the one archived doc that already lived there plus the archive convention from `CONTRIBUTING.md`; the latter lists all five generated/hand-maintained reference docs and which is which). `docs/audit/README.md` — already existing — is now linked from `docs/README.md` too.

  `scripts/consistency.js`'s existing `docs-index` check (added under an earlier phase, D2) wholesale-excluded `historical/`, `reference/`, and `audit/` from the "every doc must be reachable from `docs/README.md`" requirement. Rather than add a second, overlapping check, this narrows that exclusion list down to a single deliberate exception — `audit-archive/`, a dated-snapshot pipeline-output archive indexed by its own `HISTORY.md` rather than a `README.md`, and not part of the hand-authored-doc sprawl this check exists to catch. `historical/`, `reference/`, and `audit/` now rely on the same directory-index-coverage rule `adr/` and `runbooks/` already used — no new mechanism, just closing three exemptions that had outlived their reason. `npm run consistency` went from 376 to 397 checks passed with the new indexes in place; zero files were deleted or moved.

  Tests: `tests/consistency-meta.test.js` gained a positive test that `historical/`, `reference/`, and `audit/` are covered once each has a linked `README.md`, and a negative test that a `historical/` doc without one is still (correctly) flagged as an orphan. The pre-existing "excluded dir is not required" test encoded the old wholesale `historical/` exemption; renamed and repointed it at `audit-archive/`, the one exemption this item keeps, since that's the behavior it actually verifies now.

  Honest scope note: no documentation was moved. The only file that ever lived under `docs/historical/` (`GAP-ANALYSIS.md`) was already there from an earlier phase; this item indexed it rather than relocating anything else, because nothing else in `docs/` was found to be genuinely superseded — see the PR description for the full list the generalized check would have flagged before these fixes (all of it indexed, none of it deleted). `CONTRIBUTING.md`'s Archive policy section claims `docs/historical/` "already uses" a datestamp-prefix naming convention "for the self-audit archive" — that's actually true of `docs/audit-archive/`'s dated subdirectories, not `docs/historical/`'s one undated file; left as-is and flagged for a human, since fixing it means picking between renaming the file (and its stub redirect) or correcting the sentence.

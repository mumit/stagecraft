- **Antigravity CLI host adapter (phase-28 item 28.6) — Gemini CLI continuity.** Gemini CLI stopped serving free/Pro/Ultra requests 2026-06-18; Google's supported successor is Antigravity CLI (binary: `agy`). `hosts/antigravity/` is a thin shell over `makeMarkdownHostAdapter`, structurally identical to `hosts/codex/` and `hosts/gemini-cli/`: plain-markdown role prompts at `.agents/prompts/roles/`, skills at `.agents/skills/<name>/SKILL.md`, no hooks/slash commands/native-subagent dispatch, post-hoc git-diff write audit, headless via `agy --print --dangerously-skip-permissions` (prompt piped to stdin). Every capability was verified against the actual installed binary rather than public docs alone — `agy --help`, an authenticated live `agy --print` dispatch, and the CLI's own embedded customization-root documentation (`strings` on the binary) — because several third-party "cheat sheet" sites surfaced by web search disagreed with the real binary (e.g. claiming plugins stage under `~/.gemini/antigravity-cli/` when the actual global customization root is `~/.gemini/config/`). `devteam doctor` now warns whenever routing resolves any role or stage to `gemini-cli`, pointing at `devteam init --host antigravity`; `gemini-cli` itself is untouched and stays installed-and-functional (full retirement is a separate later item). Updated `docs/user-guide.md`'s multi-host section, README's host lists, and `tests/adapter-contract.test.js`'s shared-host arrays (gate-footer equivalence, PATCH MODE rendering, tool-budget rendering) to include the new host. *Honest scope note:* `telemetry: "estimated"` — no native usage/cost parsing was implemented for `agy`'s own JSON output in this item (that's tracked separately under item 28.3, which already shipped `estimated` for gemini-cli/generic/omnigent); `subagents`/`hooks`/`goalLoop` are declared `false` even though `agy` has some native equivalents (an `--agent` flag, plugin `hooks.json`) because Stagecraft doesn't wire into them here, matching the existing codex/gemini-cli stance of only declaring capabilities Stagecraft itself dispatches through.

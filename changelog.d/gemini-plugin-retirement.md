- **gemini-cli retired from a first-party host to a plugin package (phase-34 item 34.4, completes 28.6).** `hosts/gemini-cli/` moved to `packages/host-gemini-cli/`, a `@devteam/host-gemini-cli` package resolved through the existing A4 pluggable-adapter mechanism (`core/router.js`) rather than the first-party `hosts/` enumeration. First-party surface is now claude-code, codex, antigravity, openai-compat, acp, omnigent, and generic. `devteam init --host gemini-cli` now fails with an exact install instruction (`npm install @devteam/host-gemini-cli`) when the plugin isn't present, and succeeds identically to before once it is. `devteam doctor`'s existing gemini-cli deprecation warning (phase-28 item 28.6) now fires independent of whether the plugin is installed, and reports a plugin-specific "not available" message instead of the generic `no adapter at hosts/<name>/` text. The adapter's own behavior is unchanged — same capabilities, same contract — only its location and packaging moved; its README documents the honest scope note that this package isn't published to any registry, and that its relative `require()`s into Stagecraft's core only resolve inside a Stagecraft checkout (tracked as `docs/BACKLOG.md` item A10).
  - **Bugfix surfaced along the way:** `core/router.js`'s `listExternalHosts()` used `Dirent.isDirectory()`, which reflects a directory entry's own type — false for a symlink, even one pointing at a directory. npm workspaces and `npm link` install local packages as symlinks under `node_modules/<scope>/`, so any first-party-maintained plugin installed that way (not just gemini-cli) was invisible to `listHosts()`/`loadAdapter()`. Fixed with an explicit `fs.statSync` follow when the entry is a symlink; regression test in `tests/router.test.js`.
  - Tests: `packages/host-gemini-cli/tests/adapter.test.js` (adapter's own contract, moved from `tests/adapter-contract.test.js` and friends), `tests/gemini-cli-plugin.test.js` (init error path + plugin-installed round-trip via a symlinked fixture), plus updates across `tests/adapter-contract.test.js`, `tests/audit.test.js`, `tests/capabilities.test.js`, `tests/doctor.test.js`, `tests/fanout.test.js`, `tests/goal-loop.test.js`, `tests/orchestrator.test.js`, `tests/prompt-layout.test.js`, `tests/router.test.js`, and `tests/write-audit.test.js` to reflect gemini-cli no longer being a first-party, always-loadable host in this dev checkout. Root `package.json`'s test script now also globs `packages/*/tests/*.test.js`.
  - Honest scope note: this package is shaped to be publishable but is not actually published anywhere as part of this change (see `packages/host-gemini-cli/README.md` and `docs/BACKLOG.md` item A10).

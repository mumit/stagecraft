# docs/historical/ — archived documentation

Documentation that has been superseded moves here rather than being deleted or half-updated
in place (see [CONTRIBUTING.md § Archive policy](../../CONTRIBUTING.md#archive-policy)). A
redirect stub is left at the doc's original path when anything outside this repo may have
linked to it, so old links still resolve to an explanation instead of a 404.

Files here are exempt from the prose-vs-code consistency checks (`scripts/consistency.js`
excludes `docs/historical/` from stage-ID, track-count, and similar drift checks) — an
archived doc is expected to describe an old state, not the current one.
